# AI Summarizer Agent (ADK)

## Overview
This project implements a simple AI agent using Google's Agent Development Kit (ADK) to summarize input text.

## Features
- Accepts user input
- Generates summarized output
- Built using ADK agent structure

## Note
Due to cloud billing constraints, deployment to Cloud Run could not be completed.
However, the agent is fully functional and tested locally.

## How to Run
1. Install dependencies
2. Run: adk web
3. Open http://127.0.0.1:8000
